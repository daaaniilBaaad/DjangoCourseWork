# Курсовая работа

## Проект 4. Сервис управления рассылками "Mailsendler".

### "Mailsendler" - это веб-приложение на Django для управления рассылками электронной почты.

## Содержание проекта

 - "config" - настройки проекта
 - "mailsendler" - приложение для управления рассылками
 - "users" - приложение для управления пользователями
